# RZXXY AI

A mobile-friendly, futuristic AI-assistant-style demo website.

## Current mode

This repository currently runs in **local Demo Mode**:
- No API key or paid API service is required.
- Chat replies are generated by simple, predefined browser-side rules.
- It is not connected to a live AI model, and replies are limited to the examples in the frontend code.

## Deploy on Vercel

1. Import this GitHub repository into Vercel, or keep the existing Vercel project connected to this repository.
2. Use the `main` branch.
3. No environment variables are required for the current Demo Mode.
4. Vercel can serve the root `index.html` as a static site.

## Local preview

Open `index.html` in a modern browser.

## Project files

- `index.html` — the complete static frontend (HTML, CSS, and JavaScript).

The former `api/chat.js` OpenAI backend has been removed because Demo Mode does not call an API.

## Future live AI integration

To connect a real AI model later, add a secure server-side API route and store the provider key in Vercel Environment Variables. Never put private API keys in frontend JavaScript or commit them to GitHub.
